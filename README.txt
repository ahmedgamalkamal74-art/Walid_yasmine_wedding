# دعوة زفاف وليد الشيمي وياسمين الصاوي

الملفات جاهزة للنشر كـ Website.

## التشغيل على الكمبيوتر
افتح `index.html` في المتصفح.

## النشر على GitHub Pages
1. أنشئ Repository جديد على GitHub.
2. ارفع كل الملفات والمجلدات الموجودة هنا.
3. من Settings > Pages اختر Deploy from branch.
4. اختر Branch: main و Folder: / (root).
5. سيظهر لك رابط الموقع.
